# Sales Data Analyzer (Python)

A simple Python project that reads sales data from a CSV file and provides insights such as:
- Total sales
- Highest spender
- Product-wise sales

## Features
- List all sales records
- Calculate total sales
- Identify highest spender
- Product-wise sales (sorted from highest to lowest)
- Input validation using try-except
## New Feature
- Display Top 3 products based on sales

## Tech Used
- Python
- CSV module

## Recent Updates
- Added sorting for product sales (highest → lowest)
- Added error handling for user input using try-except

## Sample Output

Sales by product (Highest → Lowest):
Laptop: $2000
Phone: $1500
Tablet: $800

```bash
python data_analyzer.py
